## Capture boundary

The probe used one user-authorized second app process on loopback-only CDP
port `9881` with a unique profile under `/private/tmp`. Existing Codex windows
were not navigated or resized. Main Renderer selection used the application
URL, viewport area, shell landmarks, and visible-control density; the separate
avatar-overlay Renderer was rejected structurally without reading private
content.

The reproducible capture remains:

```sh
CODEX_CURRENT_BASELINE_CDP_PORT=9881 \
CODEX_CURRENT_BASELINE_PROFILE=/absolute/path/to/the/isolated/profile \
CODEX_CURRENT_BASELINE_ALLOW_NAVIGATION=1 \
CODEX_CURRENT_BASELINE_OUTPUT=/absolute/path/to/the/isolated/profile/current-baseline.json \
pnpm capture:current-baseline
```

The output is a new direct child of the isolated profile and remains
untracked. It contains package identity, sanitized target selection, fixed
public labels, computed styles, geometry, focus state, and counts, but no
screenshots or account, project, repository, or task text.

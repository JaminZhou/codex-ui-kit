## Evidence boundary and implementation correction

The CDP Browser window lookup reports `Browser window not found`, including
when given the selected target ID. Width changes therefore use Renderer
emulation and are explicitly **not native-window resize acceptance**.

The centered-card fixture introduced in #293 is useful as a generic component
regression, but it does not reconstruct this observed PDF workspace. The next
implementation must compose the tab strip, a page-aware toolbar, one document
scroller, pane expansion, narrow hide/reopen, and close/attachment ownership.
It must then pass independent replay/CDP, Electron, and owned-region product
pixel comparisons before Browser/Electron inventory statuses are promoted.

Loading, malformed/password-protected PDF, error recovery, actual annotation
editing, download, native external-app launch, multiple document tabs, light
theme, and non-PDF document formats remain open. The new observation advances
runtime reachability for the PDF and artifact-shell slice only; it does not
complete either surface family or the delivery plan.

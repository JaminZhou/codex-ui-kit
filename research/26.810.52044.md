## Capture boundary

The probe used an explicitly authorized second app process with a unique
profile under `/private/tmp` and a loopback-only CDP endpoint. Main Renderer
selection used URL, viewport area, shell landmarks, and visible-control
density rather than target order or private text. The resulting baseline JSON
contains structure, accessibility labels, fixed menu text, computed styles,
geometry, viewport, and control counts. It contains no screenshot or private
account, project, repository, or task text.

The visual inventory separately used one disposable synthetic task to run
`pwd`, expand its real `Worked for …` activity, and observe the successful
command row and completed assistant actions. Conditional unread evidence was
captured only long enough to identify the Activity attention glyph and
`Mark all as read`, then the unread state was cleared.

## Evidence boundary

These observations refresh the shell, sidebar, sampled menus, visible
Composer/workspace controls, Settings/Git navigation, and one completed
successful-command thread. They do not revalidate older failure, approval,
attachment, collaboration, Terminal-session, or native-system-dialog
lifecycles. Browser and Electron acceptance validate the independent
implementation; they are not evidence that an unsampled product surface was
reached on this build.

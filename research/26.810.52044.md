## Capture boundary

The probe used an explicitly authorized second app process with a unique
profile under `/private/tmp` and a loopback-only CDP endpoint. Main Renderer
selection used URL, viewport area, shell landmarks, and visible-control
density rather than target order or private text. The resulting baseline JSON
contains structure, accessibility labels, fixed menu text, computed styles,
geometry, viewport, and control counts. It contains no screenshot or private
account, project, repository, or task text.

The visual inventory separately used one disposable synthetic task to run
`pwd`, expand its real `Worked for …` activity, and observe the successful
command row and completed assistant actions. Conditional unread evidence was
captured only long enough to identify the Activity attention glyph and
`Mark all as read`, then the unread state was cleared.

The MCP refresh used a second exact process (`15575`) on loopback port `9841`
with profile `/private/tmp/codex-ui-kit-mcp-26-810.3DIzCN`. Accepted evidence
contains only synthetic no-project tasks that allowed OpenAI Developer Docs
Search/Fetch and explicitly disallowed shell, Browser, file, and project
actions. One diagnostic task returned the wrong documentation page and was
excluded from the baseline. The accepted canonical task completed one Search
and one Fetch in 25 seconds; the accepted recovery turn kept an invalid-URL
Fetch, Search, and canonical Fetch in one group and completed in 18 seconds.

The command refresh used another exact isolated process on loopback port
`9851` with a unique `/private/tmp` profile. It ran three bounded synthetic
commands only: a twelve-line success loop, one stdout/stderr command that
exited 7, and one 120-second loop stopped after eight seconds. Two no-tool
follow-ups then proved recovery in the same task. Raw screenshots, task text,
project metadata, and profile data remain local-only.

The worktree refresh used two fresh disposable Git repositories and isolated
profiles on loopback ports `9862` and `9863`, plus one narrow geometry replay
on `9864`. Passing the repository as a macOS open-file event before `--args`
registered the synthetic project without touching the primary process. One
path created and completed a real worktree. The other made only its disposable
`.git/worktrees` directory unreadable, reached the real failure surface, then
restored permissions and completed through Retry. Exact temporary tasks were
archived and the projects removed before the isolated processes were closed;
the original Codex process remained running.

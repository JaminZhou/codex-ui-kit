## Capture boundary

The probe used one user-authorized second app process on loopback-only CDP
port `9895` with a unique profile under `/private/tmp`. Existing Codex windows
were not navigated or resized. Main Renderer selection used the application
URL, viewport area, shell landmarks, and visible-control density. The capture
contains only the package identity, sanitized fixed labels, geometry, styles,
focus state, and content-dependent counts; screenshots and private account,
project, repository, and task text remain local-only.

The reproducible capture is:

```sh

CODEX_CURRENT_BASELINE_PROFILE=/absolute/path/to/the/isolated/profile \
CODEX_CURRENT_BASELINE_ALLOW_NAVIGATION=1 \
CODEX_CURRENT_BASELINE_OUTPUT=/absolute/path/to/the/isolated/profile/current-baseline.json \
```
